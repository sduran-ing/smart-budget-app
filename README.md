## Quick Start
*Note: The .env files are not ignored to facilitate the deployment of the app.*

### 🛠️ Installation

Clone the repository and run:

```bash
npm run install-all
```

### 🛠️ Running the app

After the installation, you can run it with:

```bash
npm run dev
```
